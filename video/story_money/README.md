# POV: минус сорок тысяч — 6 минут, 9:16

Вторая серия канала: формат storytime от первого лица (POV), тема — деньги и долги,
визуально темнее прошлого ролика (нуар-комикс). Вертикаль 1080 × 1920, 30 fps,
ровно 6:00.

| Файл | Что это |
| --- | --- |
| `minus_40k_6min.mp4` | готовый ролик (H.264 + AAC 48 kHz) |
| `minus_40k_6min.srt` | субтитры (45 реплик) |
| `kf/` | 10 кадров-иллюстраций |
| `vo/`, `vo_trim/` | сырая озвучка и обрезанная по тишине |
| `timeline.py` | единственный источник правды по таймингу (главы, графика, 360 с) |
| `audio_money.py`, `master.py` | музыка, SFX, микс и мастеринг громкости |
| `render_money.py` | рендер кадров и монтаж графики |
| `srt_money.py` | субтитры из тех же кусков текста, что видит зритель |

## Формат подачи

* **POV-история от первого лица**, без ведущего в кадре: зритель смотрит глазами героя.
* Речь идёт непрерывно и по смыслу: реплики 1,05× (немного быстрее живого темпа, чтобы держать плотность).
* Субтитры — транскрипт того, что реально говорит голос, разбитый по длине фразы; ничего не выдумано и не сокращено.
* Поверх картинки только короткие смысловые удары: «−40 000», «30 МАЛЕНЬКИХ КРЕДИТОВ», «БЫСТРЫХ ДЕНЕГ НЕТ».
* 4 графические вставки-«страницы блокнота» закрывают паузы между главами, чтобы не было мёртвого воздуха.
* В финале — чеклист из пяти шагов и CTA (комментарий + подписка + тизер следующего видео).

## Звук

* Нуарная подложка 96 BPM: редкий кик, щётки, walking bass, электропиано, винил-треск.
  Плотность и напряжение растут к главе про «быстрые деньги» и падают в финале.
* SFX по смыслу сцены: банкомат (писк, купюроприёмник, ошибка), гудки при звонке в банк,
  звон монет, вибрация телефона, whoosh на переходах, шелест бумаги на вставках.
* Мастер: **−14.5 LUFS integrated**, true peak **−1.3 dBFS** (после AAC).
* Видео: 1080 × 1920, 30 fps, ровно 6:00, H.264 (High) + AAC 160 kHz, ~22 МБ.

## Соответствие прошлой серии

Тот же пайплайн и та же дисциплина кадра (вертикаль, безопасные зоны, чтение текста с телефона),
но другой жанр: вместо кислотной комедии — тёмный нуар с единственным акцентом оранжевого и
холодным бирюзовым светом. Кадр держится дольше (глава 20–28 с), потому что это сторителлинг, а не шортс.

## Как воспроизвести

```bash
python3 timeline.py      # пересчитать тайминг глав под текущие WAV
python3 audio_money.py   # музыка + SFX + голос -> out/mix_pre.wav
python3 master.py        # громкость/пик -> out/mix_money.wav
python3 render_money.py  # кадры -> out/video_silent.mp4
./mux.sh                 # склейка со звуком и веб-копия
python3 srt_money.py     # субтитры
```
